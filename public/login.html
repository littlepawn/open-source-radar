开源雷达 我的 GitHub 收藏看板

用 GitHub token 进入

这个看板会读取你 star 和 fork 的仓库，并按你的喜好分类整理。 需要一个有 public_repo 权限的 Personal Access Token。

怎么拿 token？
  1. 打开 github.com/settings/tokens
  2. Generate new token → classic
  3. 勾选 public_repo（想收藏私有仓库再加 repo）
  4. 生成后复制，粘到上面

token 会用 AES-256-GCM 加密后存进本地 SQLite，不会出现在日志里，也不会发往除 GitHub 以外的任何地方。

本地运行 · 数据只存在你的机器上
