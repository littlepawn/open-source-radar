用法：打开任意仓库 → 详情页底部「问 AI」。已自动带上 README、目录结构和关键文件内容，所以可以直接问： 「这库和 X 比有什么取舍」「生产环境敢用吗，坑在哪」「想只用一个功能，怎么最小改造」 「这库还活跃吗，维护者是谁」「它依赖了哪些外部服务」。

自动同步

本地服务常驻时，按固定间隔自动拉一次 star / fork。默认两小时，改成你想要的分钟数即可。间隔过短会打光 GitHub 的 API 配额（未认证 60 次/小时，一次全量同步要翻几十页），所以下限 15 分钟。
